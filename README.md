# 🏗️ WorkersHub

WorkersHub is a web platform that connects **Builders** and **Workers**.  
Builders can post job opportunities, and workers can browse and apply for work.

---

## 🚀 Features

### 👷 Worker
- Browse available jobs
- Apply for jobs
- View completed work
- Maintain a personal profile

### 🏗️ Builder
- Post new job listings
- View applicants
- Accept / Reject workers
- Mark jobs as completed

---

## 🔐 Authentication
- Secure login & signup using JWT
- Role-based access (Worker / Builder)

---

## 🛠️ Tech Stack

- **Backend:** Node.js, Express.js  
- **Frontend:** EJS, CSS, Bootstrap  
- **Database:** MongoDB + Mongoose  
- **Authentication:** JWT  
- **File Uploads:** Multer + Cloudinary
